When you have a lot of keys, it takes longer to find the right one. A
**category** is a label you put on keys to tidy them up, such as `Work`,
`Family`, or `Servers`.

A category changes nothing about the keys themselves. It only changes what you
see.

<Aside type="note" title="Not the same as a key group">

A **key group** is a shortcut for encrypting to several people at once. It
shows up in the key list, and you can pick it as a recipient.

A **category** never does that. It is only a way of sorting the list. If you
want to encrypt to several people at once, see
[Key Group](/guides/key-group/).

</Aside>

## Where to Find Them

Categories appear in two places:

- **KeyPair Management** window: a list down the left side. This is where you
  create and change categories.
- **Key ToolBox** in the main window: a thin coloured strip. You can switch
  between categories here, but not edit them.

Click a category to show only the keys in it.

## The Ready-Made Ones

Some categories are built in. GpgFrontend fills them for you.

The **KeyPair Management** window has these:

- **All**: every key.
- **Key Group**: your key groups.
- **Only Public Key**: keys you have no private key for. These are other
  people's keys.
- **Has Private Key**: keys you own.
- **Expiring Soon**: keys that expire soon. At first that means within the
  next 30 days. You can change the number of days (see the tip below).
- **No Primary Key**, **Revoked**, **Expired**, **Disabled**: keys with a
  problem.

The **Key ToolBox** has a shorter list, made for picking keys:

- **Default**: every key you can use. Expired, revoked and disabled keys are
  left out.
- **Key Group**, **Only Public Key** and **Has Private Key**: as above, but
  again without expired, revoked and disabled keys.

You cannot rename or delete the built-in categories.

<Aside type="tip" title='Change what "soon" means'>

Open **Settings**, go to **General**, and set **Warn about keys expiring
within** to the number of days you want.

</Aside>

## Make Your Own

<Steps>

1. Open the **KeyPair Management** window.

2. Click the **+** button at the bottom of the category list, or right-click
   the list and choose **New Category...**. The **New Category** window opens.

3. Type a **Name**, such as `Work Contacts`. A name can be up to 64
   characters. Two categories cannot have the same name, and upper and lower
   case count as the same.

4. Under **Colour**, click one of the colours. A colour no other category
   uses is already picked for you. For any other colour, click the last one
   (**Custom Colour...**).

   The top of the window shows how the category will look in the list.

   ![The New Category window][img-3]

5. Click **Create**.

</Steps>

You can also make a category and put keys in it in one go:

- In the **KeyPair Management** window, select some keys and right-click
  them. Open the **Category** submenu and choose **New Category...**. The
  window then says how many of the selected keys will be added to the new
  category.
- In the main window, right-click a key in the Key ToolBox. Open the **Add To
  Category** submenu and choose **New Category...**. This works for one key
  at a time.

<Aside type="note" title="Changed in v2.2.4">

Making or changing a category now uses one window, with the name, the colour
and a preview together. It used to ask for the name and the colour in two
separate small windows.

</Aside>

## Put Keys in a Category

<Steps>

1. Find the key in the key list of the **KeyPair Management** window. You
   can select several keys at once.

2. Right-click the key and open the **Category** submenu.

   ![The Category submenu of a key's right-click menu][img-4]

3. Click the category you want. A tick appears beside it.

</Steps>

In the Key ToolBox of the main window, the submenu is called **Add To
Category**. It works the same way, for one key at a time.

To take a key out again, open the submenu and click the ticked category once
more. Or click that category in the category list, right-click the key, open
the same submenu and choose **Remove From This Category**.

A key can be in as many categories as you like.

## Rename, Recolour, Reorder

Right-click a category in the **KeyPair Management** window to find:

- **Set Colour...** and **Reset Colour**: change only the colour. These work on
  the built-in categories too.
- **Edit Category...**: change the name and colour in the same window as
  above. Click **Save** when you are done. (Before v2.2.4 this was **Rename
  Category**.) Only for your own categories.
- **Delete Category...**: remove the category. Only the label goes. Your keys
  are never touched. Only for your own categories.

To change the order, drag a category up or down the list. GpgFrontend
remembers the order.

<Aside type="note" title="Where the Favourite tab went">

GpgFrontend v2.2.2 replaced the old **Favourite** tab with categories. Old
favourites are not carried over. Make a category and put those keys back in
it.

</Aside>

## Good to Know

- Categories belong to one key database. If you use more than one key
  database, each has its own set of categories. See
  [Multi-Key Database](/advanced/key-database/).
- The search box only searches the category you are looking at.
