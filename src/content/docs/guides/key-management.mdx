The **KeyPair Management** window is where you look after your keys. To open
it, click the **Manage Keys** button in the toolbar of the main window.

The Key ToolBox in the main window and this window show the same keys, but they
are for different jobs. The Key ToolBox is for **picking** a key for a task.
This window is for **doing something to** a key.

![KeyPair Management window][img-1]

## What You Are Looking At

The window has three parts:

- **Down the left**: your categories. Click one to show only those keys. See
  [Key Categories](/guides/key-categories/).
- **In the middle**: your keys, one per row.
- **Above the list**: the search box and a row of buttons. The buttons
  refresh the list (**Refresh**), tick or untick all keys (**Check All**,
  **Uncheck All**), make a [key group](/guides/key-group/) (**New Key
  Group**), choose which columns to show (**Columns**), and switch to another
  key database.

## Find a Key

Type in the search box above the list. It looks at the name, the email
address, the key ID, and the fingerprint. Any of those will find the key.

You can paste a fingerprint with spaces in it. It still matches.

- <kbd>Ctrl</kbd>+<kbd>F</kbd> jumps to the search box.
- <kbd>Escape</kbd> clears it.
- <kbd>F5</kbd> reads the key list again (**View** > **Refresh Key List**).
- Click a column heading to sort by it. Click again to reverse it.

## The Line Along the Bottom

The bottom of the window shows four counts: how many keys you have, how many
of them have a private key, how many expire soon, and how many have expired or
been revoked.

This line is the quickest way to notice that something needs your attention.
If it says a key is expiring soon, click the **Expiring Soon** category to see
which one.

## Right-Click a Key

This is where most of the work happens. Right-click any key for a menu of
things you can do to it. All of this is new in v2.2.2.

The menu only lists what you can do with the key you clicked. For example,
**Export Private Key...** is missing for a key you have no private key for.

![The right-click menu of a key, with Key Operations open][img-2]

### Look at it

- **Show Key Details**: everything about the key. See
  [Key Pair Details](/guides/view-keypair-info/).

### Copy something

These are in the **Copy** submenu.

- **Copy Fingerprint**: the long code people use to check they have the right
  key. This is the one to read out over the phone.
- **Copy Key ID**: a shorter code. Easier to type, but less exact.
- **Copy Email**: the address on the key.
- **Copy Public Key Block**: the whole public key as text, ready to paste into
  an email or a web page.

### Save it to a file

These are in the **Export** submenu.

- **Export Public Key...**: saves the public key, which you can safely give
  away.
- **Export Private Key...**: saves the private key, which you must keep to
  yourself.
- **Export As OpenSSH** <Badge text="GnuPG only" variant="note" />: saves one key in the format SSH uses (SSH is a way
  to log in to another computer). It is hidden when your OpenPGP engine
  cannot do it, such as rPGP.

For more ways to export, see
[Import & Export Key Pair](/guides/import-export-key-pair/).

<Aside type="caution" title="Be careful with the private one">

A private key file is your identity. Anyone who gets it can read messages sent
to you and sign things as you.

Save it somewhere only you can reach, such as an encrypted drive. Never send
it to anyone.

</Aside>

### Change it

These are in the **Key Operations** submenu.

- **Certify Key...**: certify (sign) every user ID of a key, to say you have
  checked it is really theirs. See
  [Trust Chain Management](/guides/openpgp-trust-manage/).
- **Set Expiry...**: change when the key expires, or make it never expire.
- **New Subkey**: add a subkey to your key. See
  [Subkeys](/guides/generate-use-subkey/).
- **Set Owner Trust Level**: say how much you trust the key's owner to check
  other people's keys. See
  [Trust Chain Management](/guides/openpgp-trust-manage/).
- **Generate Revocation Certificate...**: make the file that lets you cancel
  (revoke) this key later. Do this now, not when you need it. See
  [Key Revocation](/advanced/key-revocation/).

You also find these in the **Operations** menu at the top of the window, and
under the **Key Operations** button in the toolbar.

### Sort it or delete it

- **Category**: put the key in one of your categories, take it out with
  **Remove From This Category**, or make a new one with **New Category...**.
  See [Key Categories](/guides/key-categories/).
- **Delete Selected Keys**: delete the keys you selected. The <kbd>Delete</kbd>
  key on your keyboard does the same. GpgFrontend asks you to confirm first. To
  delete the ticked keys instead, use **Key** > **Delete** > **Delete Checked
  Keys**.

<Aside type="danger" title="Deleting is permanent">

Deleting a private key cannot be undone. Make a backup first.

</Aside>

### Key servers

A key server is a website that stores public keys, so people can find each
other's keys.

- **Publish Public Key to Key Server**: upload your public key so others can
  find it.
- **Refresh Public Key From Key Server**: fetch the latest copy of a key, in
  case the owner has changed or revoked it.

You also find both items in the **Operations** menu at the top of the window.

Both act on the keys you have ticked. If you have not ticked any, they act on
the row you clicked. They do not work on a key group.

To look someone up on a key server, open **Key** > **Import Key** and choose
**Key Server**.

For the full steps, see
[Key Server Operations](/guides/key-server-operations/).

<Aside type="note" title="Changed in v2.2.3">

The key server items now come from a module (an add-on) that comes with
GpgFrontend. If the module is turned off, these items are not in the menus.
See [Module Controller](/advanced/module-controller/).

</Aside>

## Work on Several Keys at Once

<Steps>

1. Tick the box beside each key you want.

2. Open the **Operations** menu and choose **Bulk**.

   ![The Bulk menu under Operations][img-3]

3. Pick what to do:

   - **Set Owner Trust for Checked Keys...**: give them all the same trust
     level.
   - **Extend Expiry of Checked Keys...**: set a later expiry date on all of
     them at once. Useful when several keys expire around the same time. It
     only changes keys you have the private key for.
   - **Back Up All Private Keys...**: save every private key in this key
     database into one file, a [KeyPackage](/advanced/key-package/). This is
     the best way to make a full backup. It does not matter which keys are
     ticked.

</Steps>

<Aside type="note" title='What "checked" means'>

Ticking a box and clicking a row are two different things. "Checked" means
the box is ticked.

The two bulk actions that say **Checked** work on the ticked keys. If you have
not ticked any key, they use the rows you selected instead.

**Delete Checked Keys** is stricter. It only works on ticked keys.

</Aside>

## When an Action Is Greyed Out

The right-click menu leaves out what you cannot do with the key you clicked.
The menus at the top of the window show those items greyed out instead.

If a menu item is greyed out, hover over it. The tooltip says why.

The usual reasons are simple:

- **"Select a key first."** Nothing is selected.
- **"Select exactly one key for this."** The action only works on one key at
  a time.
- **"Only available for a key, not a key group."** You selected a key group.
- **"Only available for a key you own the private half of."** You cannot change
  someone else's key.
- **"This key carries no email address."** There is nothing to copy.
- **"You need a private key to certify with."** Certifying uses one of your
  private keys, and you have none.

Some actions are missing from every menu. These are actions your OpenPGP
engine cannot do at all. So a short menu usually means you are on the rPGP
engine. See [Multi-Key Database](/advanced/key-database/).
