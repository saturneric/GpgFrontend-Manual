This page takes you from nothing to a running GpgFrontend. You pick an
engine, install the app, and open it for the first time. It takes a few
minutes.

## Step 1: Choose Your Engine

GpgFrontend is the window you click in. The encryption work itself is done by
a part called the **engine**. There are two engines:

- **GnuPG**: a well-known encryption program. On some systems you install it
  yourself.
- **rPGP**: a newer engine that is built into GpgFrontend.

Find your system in the table to see which engine to use:

| System           | Recommended Engine  | What you need to do                                          |
| :--------------- | :------------------ | :----------------------------------------------------------- |
| **Windows**      | **GnuPG** (bundled) | Nothing. GnuPG comes with GpgFrontend.                       |
| **macOS**        | **GnuPG**           | Install GnuPG with Homebrew: `brew install gnupg`.           |
| **macOS (Lite)** | **rPGP** (built-in) | Nothing. This is the Mac App Store version. It has no GnuPG. |
| **Linux**        | **GnuPG**           | Usually nothing. To check, run `gpg --version`.              |
| **BSD**          | **GnuPG**           | Install GnuPG yourself with ports or pkg.                    |

<Aside type="note" title="Which GnuPG version?">
  GpgFrontend needs GnuPG 2.2.0 or newer for full support. If GnuPG is
  missing, or older than 2.1.0, GpgFrontend does not use it. It uses the
  built-in **rPGP** engine instead, so the basics keep working.
</Aside>

## Step 2: Install GpgFrontend

Pick your system below. The steps use the direct download. To install from an
app store or a package manager instead (for example WinGet or Flatpak), see
the [Downloads](/overview/downloads/) page.

<Tabs syncKey="os">
<TabItem label="Windows">

### Installer (Recommended)

<Steps>

1. **Download** the `.msi` installer from the
   [Downloads](/overview/downloads/) page.
2. **Open** the file. Accept the license, then click **Next** until it is
   installed.
3. **Start** GpgFrontend from the new shortcut on your desktop.

</Steps>

### Portable Version

<Steps>

1. **Download** the `windows-x86_64-portable.zip` file from the
   [Downloads](/overview/downloads/) page. To find it, open
   **More download options** in the download box.
2. **Unpack** the ZIP file into any folder you like.
3. **Open** the `bin` folder inside it and run `GpgFrontend.exe`.

</Steps>

</TabItem>
<TabItem label="macOS">

<Steps>

1. **Install GnuPG** with Homebrew: open the Terminal app and run
   `brew install gnupg`.
2. **Download** the `.dmg` file from the [Downloads](/overview/downloads/)
   page.
3. **Open** the `.dmg` file and drag **GpgFrontend** into your
   **Applications** folder.

   ![Drag to Applications][img-1]

4. **Start** GpgFrontend from your **Applications** folder.

</Steps>

</TabItem>
<TabItem label="Linux">

<Steps>

1. **Check GnuPG**: open a terminal and run `gpg --version`. If the command
   is not found, install GnuPG (`sudo apt install gpg` or
   `sudo dnf install gnupg`).
2. **Download** the `.AppImage` file from the
   [Downloads](/overview/downloads/) page.
3. **Allow it to run**: in the folder with the download, run
   `chmod u+x ./GpgFrontend-xxx.AppImage`. Replace `GpgFrontend-xxx.AppImage`
   with the real file name.
4. **Start** it: double-click the file, or run it from the terminal.

</Steps>

</TabItem>
<TabItem label="BSD">

There is no ready-made download for BSD yet. You have to **build GpgFrontend
from source**. The build instructions are in the
[GpgFrontend repository][github-gpgfrontend] on GitHub.

</TabItem>
</Tabs>

<Aside type="note" title="Installed or portable?">
  Most downloads come in two versions. The **installed** version is the normal
  choice. The **portable** version keeps everything in its own folder, so you
  can run it from a USB drive. The two do not share settings or keys, so pick
  one before you start. See
  [Portable Version](/overview/downloads/#portable-version) on the Downloads
  page.
</Aside>

## Step 3: The First Time You Open It

When GpgFrontend starts, a small **Starting GpgFrontend** window may appear. It
shows a progress bar while your keys and modules load. Wait for it to finish.
The main window then opens.

The first time GpgFrontend runs, a short **Welcome to GpgFrontend** window
also appears. It has three pages:

1. **Welcome to GpgFrontend**. This page has a **Language:** list. Pick your
   language there. The window switches to it straight away, so you do not have
   to read the rest in English.
2. **Choose a guide**. This page has links to guides for the basics. You can
   skip it.
3. **Ready to use**. This page has two checkboxes:
   - **Check for updates on startup**. It is off unless you tick it. If you
     tick it, GpgFrontend quietly checks for a new version at most once a
     day. See [Settings](/guides/settings/#the-updates-page). Sandboxed
     builds, such as Flatpak, do not show this checkbox.
   - **Don't show this setup wizard again**. It is already ticked. If you
     finish the window with it ticked, the window does not come back. If you
     untick it, or close the window early, the window opens again at the
     next start.

Nothing in this window is permanent. You can close it at any point, and you
can change everything it sets later in **Settings**. To see the window again,
click **Help** > **Open Wizard**.
