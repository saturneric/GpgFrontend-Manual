## Portable Version

The download button gives you the normal (installed) version. It keeps your
settings and keys in your user folder.

The portable version keeps everything in the program's own folder instead.
You can run it from a USB drive and leave nothing behind on the computer.

To get it, click **Download the portable version** under the download button
at the top of this page. It is there for Windows and Linux. There is no
portable version for macOS.

The two versions do not share any data. If you switch from one to the other,
you start with empty settings and no keys. So pick the one you want before
you start. See [Portable Mode](/advanced/portable-mode/).

## Older Versions Still Supported

The **series** is the first two numbers of a version: `2.2.4` belongs to
series 2.2. A new series comes out about every two months. An older series
can still get fixes for a while after that.

Take an older series only if you need it. For example, when your system
cannot run the latest version.

The list below is always up to date. It shows each older series that still
gets fixes, and until when. Click one to see its downloads.

To learn how long a series gets fixes, see
[When a Series Gets Old](/appendix/version-policy/#when-a-series-gets-old).

<Aside type="note" title="Changed in v2.2.3">
  Qt is the toolkit GpgFrontend is built with. There are no Qt5 builds of
  v2.2.x and later. Only the 2.1 series has them, marked **Qt5 build** in its
  list above. If your system needs one, for example Windows 7, take the 2.1
  series.
</Aside>

## Test Versions

Test versions let you try what is coming next, before it is released. They
may have bugs. Do not use them for anything you cannot afford to lose.

There are three kinds. The box below shows only the ones that exist right
now.

| Kind              | What it is                                                                                             | Your keys and settings                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Release candidate | An early version of the next feature release, like `2.4.0-rc.1`. There is one only shortly before it. | Shared with your everyday GpgFrontend. Back up your keys first.           |
| Beta              | A test build of the next fix release of one series.                                                    | Shared with your everyday GpgFrontend. Back up your keys first.           |
| Nightly build     | An automatic build of the newest code. It can be broken.                                               | Kept apart. It runs as a separate app, **GpgFrontend Testing**.           |

For more, see
[Stable, Beta, Release Candidate and Nightly](/appendix/version-policy/#stable-beta-release-candidate-and-nightly).

<Aside type="note" title="New in v2.2.5">
  GpgFrontend can tell you about betas and release candidates. Open
  **Edit** > **Settings** > **Updates** (on macOS: **Preferences**) and tick
  **Also offer beta versions**. **Help** > **Check for Updates** then lists them as
  extra choices. They are never picked for you.
</Aside>

## If the Download Does Not Work

The same files are also on these sites:

- [**GitHub Releases**][github-releases]: every version, with release notes.
- [**Mirror site**][ftp-gpgfrontend]: the same files from another source, with
  no tracking or sign-in.

### Find the Right File by Name

On these sites you pick the file yourself. Its name tells you what it is for:

| Name ends with           | What it is for                                                   |
| ------------------------ | ---------------------------------------------------------------- |
| `-windows-x86_64.msi`    | Installer for Windows (recommended).                             |
| `-windows-x86_64.msix`   | MSIX installer for Windows.                                      |
| `-macos-<ver>.dmg`       | Mac with Apple chip. `<ver>` is the lowest macOS version needed. |
| `-macos-<ver>-intel.dmg` | Mac with Intel chip. `<ver>` is the lowest macOS version needed. |
| `-linux-<arch>.AppImage` | Linux app. Make it executable, then run it.                      |
| `-android-<arch>.apk`    | Android app. Only in test versions for now.                      |
| `-portable`              | Marks the portable version (a `.zip` file on Windows).           |
| `-qt5-` (in the name)    | Qt5 build for older systems. Only in the 2.1 series.             |
| `.sig`                   | Signature file of a release, to check the download is genuine.   |
| `.sigstore.json`         | Signature of a test version's checksum list (`SHA256SUMS.txt`).  |

To check that a file is genuine, see
[How to check a download](/appendix/code-binary-verify/).
