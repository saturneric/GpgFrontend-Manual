      **GpgFrontend Lite** is the edition for the Mac App Store. It has no
      GnuPG and uses only the **rPGP engine**. It cannot use smart cards or
      other hardware tokens. For those, install the regular desktop edition
      with Homebrew or the download button above. To compare the two
      editions, see the
      [FAQ](/overview/faq/#gpgfrontend-lite-mac-app-store).

      **Back up your keys right away.** Lite stores your keys inside an Apple
      sandbox, a private storage area that belongs to the app. Removing the
      app or resetting your system can erase them. Lost keys mean your data is
      gone for good.

## Other Downloads

Most people never need this part. It is for special cases.

### Portable Version

The download button gives you the normal (installed) version. It keeps your
settings and keys in your user folder.

The portable version keeps everything in the program's own folder instead.
You can run it from a USB drive and leave nothing behind on the computer. To
get it, open **More download options** in the box above. There is no portable
version for macOS.

The two versions do not share any data. If you switch from one to the other,
you start with empty settings and no keys. So pick the one you want before
you start. See [Portable Mode](/advanced/portable-mode/).

### Older Versions and Backup Sites

- [**Older version (v2.1.x)**][github-v2-1-x]: only for a system that cannot
  run v2.2.x, or if you need the older GnuPG-only build. See the note below.
- [**GitHub Releases**][github-releases]: every version, with release notes.
  Use it if the download button does not work.
- [**Mirror site**][ftp-gpgfrontend]: the same files from another source, with
  no tracking or sign-in.

<Aside type="note" title="Changed in v2.2.3">
  Qt is the toolkit GpgFrontend is built with. There are no Qt5 (`-qt5-`)
  builds of v2.2.x any more. Qt5 builds exist only for the older v2.1.x line.
  If your system needs one, for example Windows 7, download a
  [v2.1.x release][github-v2-1-x].
</Aside>

### Find the Right File by Name

On GitHub and the mirror site you pick the file yourself. Its name tells you
what it is for:

| Name ends with                 | What it is for                                                   |
| ------------------------------ | ---------------------------------------------------------------- |
| `-windows-x86_64.msi`          | Installer for Windows (recommended).                             |
| `-windows-x86_64.msix`         | MSIX installer for Windows.                                      |
| `-macos-<ver>.dmg`             | Mac with Apple chip. `<ver>` is the lowest macOS version needed. |
| `-macos-<ver>-intel.dmg`       | Mac with Intel chip. `<ver>` is the lowest macOS version needed. |
| `-linux-<arch>.AppImage`       | Linux app. Make it executable, then run it.                      |
| `-android-<arch>.apk`          | Android app. Only in test builds for now.                        |
| `-portable`                    | Marks the portable version (a `.zip` file on Windows).           |
| `.sig`                         | Signature file of a release, to check the download is genuine.   |
| `.minisig`                     | Signature file of a test build.                                  |

### Test Builds

Test builds (also called nightly builds) are made automatically from the
newest code. They are less tested, so do not use them for anything you cannot
afford to lose. For more, see "What are Nightly versions?" in the
[FAQ](/overview/faq/#using-gpgfrontend).
