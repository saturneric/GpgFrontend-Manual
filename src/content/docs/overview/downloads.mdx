Other options, for special cases only:

- [**Older Version (v2.1.x)**][github-v2-1-x]: only if you specifically need the GnuPG-only build, or a Qt5 build for an older system such as Windows 7.
- [**Nightly Builds**][github-nightly]: early test builds for testers and contributors, not for everyday use.
- [**Mirror Site**][ftp-gpgfrontend]: the same files from another source, with no tracking or sign-in.

### Installed or Portable?

Most downloads come in two versions, and you need to pick one:

- **Installed**: the normal choice. Your settings and keys are stored in your
  user folder.
- **Portable**: everything stays in the program's own folder, so you can run it
  from a USB drive and leave nothing behind.

The two versions do not share any data. If you switch from one to the other,
you start with empty settings and no keys. So pick the one you want before
you start. See [Portable Mode](/advanced/portable-mode/).

For macOS there is only an installed version.

### Understanding the File Names

Use this table to find the right file for your system.

| Filename Pattern               | What It's For                                                    |
| ------------------------------ | ---------------------------------------------------------------- |
| `-windows-x86_64.msix`         | Modern MSIX installer for Windows (Recommended).                 |
| `-windows-x86_64.msi`          | Standard MSI installer; made for enterprise setups.              |
| `-macos-<ver>.dmg`             | macOS disk image; `<ver>` shows the lowest macOS version needed. |
| `-linux-<arch>.AppImage`       | Standalone Linux app. Make it executable, then run it.           |
| `-portable`                    | Marks the portable version of a build.                           |
| `*.sig`                        | Signature file. Always use it to check the download is genuine.  |

<Aside type="note" title="Changed in v2.2.3">
  There are no Qt5 (`-qt5-`) builds of v2.2.x any more. Qt5 builds exist only
  for the older v2.1.x line. If your system needs one, for example Windows 7,
  download a [v2.1.x release][github-v2-1-x].
</Aside>

### About Nightly Builds

[Nightly builds][github-nightly] are made automatically from the newest code.
They are less tested, so do not use them for anything you cannot afford to
lose.

- Like stable releases, they come as **installed** or **portable**. There is
  no portable build for macOS.
- For macOS there is only a `.dmg` file. Apple has checked it (it is
  notarized).
- The downloads are larger than stable ones, because they include extra
  information for finding bugs. The app runs just as fast.
- They are not GPG-signed, so there are no `.sig` files. Use the
  `SHA256SUMS.txt` file instead. See
  [Checking a Nightly Build](/appendix/code-binary-verify/#checking-a-nightly-build).

      Store experience. If you want the full experience, including GnuPG support
      and advanced hardware token support, install the standard Desktop Edition
      via Homebrew or GitHub.

      lost keys mean your data is gone for good.
